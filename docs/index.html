Key Features

📦

Full STIX 2.1 Support

Complete support for STIX Domain Objects, Relationship Objects, and Cyber Observables with intelligent rendering for each type.

📱

Installable PWA

Install directly on your mobile device. Works standalone without relying on any backend services.

🔍

Explore Intel

Browse and search across all your loaded bundles. Find threats by name, type, description, or ID instantly.

⭐

Favorite & Tag

Bookmark important objects and mark them as read. Your data stays on your device, always private.

📵

Offline Ready

Full offline capability. Load bundles once, read them anywhere - no network required.

🚫

Defanged Display

URLs and IPs automatically defanged for safe analysis. Toggle to see the real values when needed.

🌙

Dark Mode

Easy on the eyes. Dark theme optimized for mobile reading with system preference detection.

🔗

GNAT Integration

Connect to your GNAT instance. Browse dissemination feeds and link back to GNAT for deep analysis.

Why PrairieGNAT?

⚡

Lightweight

About 25 KB gzipped. One of the smallest STIX readers available, with zero external dependencies for parsing.

🏠

Home Companion

Designed specifically as a GNAT Home Companion. Complements your GNAT workflow for field analysis and triage.

🔒

Private by Default

All data stays on your device. No tracking, no analytics, no external calls for your threat intelligence.

📚

Open Source

Apache 2.0 licensed. Community-driven development with transparent roadmap and active contribution welcome.

Installation

Web Installation (Recommended)

Visit prairiegnat.pages.dev on your device and install the app:

1

iOS (Safari)

Tap Share → "Add to Home Screen"

2

Android (Chrome)

Tap menu → "Install app"

3

Desktop

Click install icon in address bar

Load Your First Bundle

Once installed, you have four ways to load STIX bundles:

📂

Open Bundle File

Select a .json or .stix file from your device

🧪

Load Test Bundle

Try with sample data to explore features

📋

Paste JSON

Paste raw STIX bundle JSON directly

🔗

Load from URL

Fetch from HTTP endpoint or TAXII server

Source Code

Build locally from source:

git clone https://github.com/wrhalpin/PrairieGNAT cd PrairieGNAT npm install npm run dev # Development server npm run build # Production build
