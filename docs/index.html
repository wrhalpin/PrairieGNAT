Features

📦

STIX 2.1 Support

Full support for STIX Domain Objects, Relationship Objects, and Cyber Observables with type-specific rendering.

📱

Installable PWA

Install on iOS, Android, and desktop. Standalone, offline-capable application with zero server dependencies.

🔍

Cross-Bundle Search

Search across all loaded bundles by name, description, ID, and type with context snippets and filtering.

⭐

Bookmarks & Read State

Mark objects as read and bookmark favorites. Persistent storage with per-bundle filtering and counts.

🚫

Defanging

Auto-defang URLs and IPs. Toggle between fanged/defanged view. Copy either version to clipboard.

🔗

GNAT Integration

Connect to GNAT instance. Browse dissemination feed, fetch bundles via TAXII 2.1, deep link to GNAT.

🌙

Dark Mode

System-aware dark mode with carefully tuned colors for readability and reduced eye strain.

📊

TLP Filtering

Quick-filter objects by Traffic Light Protocol (CLEAR, GREEN, AMBER, RED) for analyst triage.

Installation

Web (Recommended)

Visit prairiegnat.pages.dev and install the PWA:

  • iOS (Safari): Tap Share → Add to Home Screen
  • Android (Chrome): Tap menu → "Install app"
  • Desktop (Chrome): Click install icon in address bar

Source Code

Clone and build locally:

git clone https://github.com/wrhalpin/PrairieGNAT cd PrairieGNAT npm install npm run dev # Development server npm run build # Production build npm run preview # Preview production build

Why PrairieGNAT?

Lightweight: At 19.7 KB gzipped, PrairieGNAT is one of the smallest STIX readers available, with zero external dependencies for parsing.

Offline First: Works completely offline after initial load. Service worker caching ensures reliable operation in field conditions.

GNAT-Aware: Designed specifically for analysts working with GNAT outputs. Integrates with TAXII 2.1 and REST API for seamless dissemination workflows.

Open Source: Apache 2.0 licensed. Community contributions welcome. Transparent development with clear roadmap.
