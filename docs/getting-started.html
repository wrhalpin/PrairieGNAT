Getting Started with PrairieGNAT

Load your first STIX bundle in 3 minutes

Installation

1. Visit the Web App

Open https://prairiegnat.pages.dev in your browser.

2. Install as PWA

On iOS (Safari):

  1. Tap the Share button at the bottom
  2. Scroll down and tap "Add to Home Screen"
  3. Tap "Add" in the confirmation dialog

On Android (Chrome):

  1. Tap the menu (⋮) in the top right
  2. Tap "Install app"
  3. Confirm the installation

On Desktop (Chrome/Edge):

  1. Look for the install icon in the address bar
  2. Click the icon
  3. Confirm installation

3. Load Your First Bundle

When you open PrairieGNAT, you'll see the Library view with three ways to load bundles:

📂 Open Bundle File

Click to select a STIX bundle JSON file from your device (.json or .stix format).

🧪 Load Test Bundle

Try the included test bundle with sample STIX objects to explore features without your own data.

📋 Paste JSON

Paste raw STIX bundle JSON directly. Useful for bundles from email or messaging apps.

🔗 Load from URL

Fetch a bundle from HTTP endpoint or TAXII 2.1 server with optional API key authentication.

4. Explore Your Bundle

Once loaded, you'll see:

  • Library: All loaded bundles with bookmark counts
  • Bundle Detail: Objects grouped by type (Indicator, Malware, etc.)
  • Object Detail: Full details with defanged URLs/IPs, related objects
  • Search: Find objects across all bundles

5. Use Key Features

⭐ Bookmarks

Click the star icon on any object to bookmark it. Filter your library by "Bookmarked" tab to see only starred items.

✓ Read State

Mark objects as read with the checkmark toggle. Read objects show a green indicator in the object list.

🚫 Defanging

On URLs and IPs, click the eye icon to toggle between fanged (real) and defanged safe versions. Copy either version.

🔍 Search

Use the Search tab to find objects across all loaded bundles. Filter results by object type or bundle source.

6. GNAT Mode (Optional)

To connect to a GNAT instance:

  1. Go to Settings (⚙️ tab)
  2. Select "GNAT-aware (Phase 3)"
  3. Enter your GNAT instance URL (e.g., https://gnat.example.com)
  4. Enter your API key
  5. Click "Test Connection"
  6. Click "Save Settings"

Once configured, a "📡 Feed" tab appears with your dissemination reports.

Tips & Tricks

  • Dark mode: Click the 🌙 icon to toggle. Defaults to system preference.
  • Offline: The app works fully offline after first load. Service worker caches everything.
  • Large bundles: Bundles with 1000+ objects use virtualization for smooth scrolling.
  • TLP filtering: In Bundle view, quickly filter by TLP (CLEAR, GREEN, AMBER, RED).
  • Cache clearing: Go to Settings to clear all cached bundles and start fresh.

Troubleshooting

❓ "Bundle not found" error

Make sure the bundle is valid STIX 2.1 JSON. Check that it has an "id" field and "objects" array.

❓ App won't install on iOS

Make sure you're using Safari (not Chrome). iOS PWAs require Safari for installation. Also check that you're on iOS 16.4+.

❓ GNAT connection fails

Check that your GNAT instance URL is correct and accessible. Verify your API key is valid. Check that HTTPS is used.
